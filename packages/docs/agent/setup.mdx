Koharu Agent can use Codex, Pi, or AGY inside the editor. Open a project, select **Agent** on the right, then choose **Agent backend**. Each backend uses its own sign-in. Changing backend, model, or setup starts a new conversation; configuration is locked while a request runs.

## Pi and AGY

Install the CLI and sign in with it first. Pi requires version 1.4 or newer in the 1.x series (`@earendil-works/pi-coding-agent`); AGY 1.4.11 was used for verification. Select **Pi** or **AGY**, then use **Check connection** to discover its models. Neither option requires a Codex account. Koharu reports missing executables, unsupported CLI versions, unavailable models and sign-in errors in the panel.

**Advanced setup** accepts the CLI executable or JavaScript entry point, Node executable when needed, a model ID and an optional reasoning level. Empty paths use automatic detection; Automatic model/reasoning uses the CLI's defaults. Pi can use `dist/cli.js` from its installed package. AGY uses `agy.exe` on Windows.

Koharu keeps one CLI process for the conversation, provides its project tools through a private connection, and revokes tool access between requests. Closing the editor or switching projects keeps a running request attached to its original project. Stop retains completed undoable edits and terminates the request; after a CLI failure or cancellation the next request starts a fresh CLI session with the current project context.

The CLI runs in a private temporary workspace. Koharu does not change global MCP configuration, install a global extension, or copy CLI credentials. Pi uses an explicitly loaded extension with built-in file/shell tools disabled. AGY uses a workspace plugin and an agent with no built-in tool components; its MCP tools are injected by the CLI.

## Codex

Codex uses ChatGPT device-code sign-in; you do not enter an OpenAI API key for the editor Agent.

<Steps>
  <Step title='Open the Agent panel'>Open a project and select **Agent** on the right.</Step>
  <Step title='Authorize the device'>
    Choose **Sign in with Codex**. Koharu opens the authorization page in your browser; enter the
    code shown in the panel and approve the sign-in for your account. The code expires after 15
    minutes.
  </Step>
  <Step title='Choose a model'>
    Return to Koharu and wait for the account and model list. Select a Codex model and reasoning
    level at the top of the Agent panel; **Automatic** uses the first available model. More
    reasoning can help with ambiguous edits but takes longer.
  </Step>
</Steps>

Only one sign-in attempt can run at a time. Cancel it before starting another.

## Background work and progress

One Editor Agent request can run at a time. Start it on project A, then open project B to translate or edit: the Agent continues on A. Activity shows its project, current tool/page, completed edits and Stop. Open A again to see the conversation and committed layer changes. An idle conversation retains its project session and Undo history until that session is replaced or cleared.

Agent edits do not refresh another project's canvas. If a user changes relevant project data after the Agent inspected it, a stale edit is rejected and the Agent must read the current state again. An external pipeline cannot start on the same project while its Agent is editing. Agent-requested OCR/translation/inpainting waits for the existing processing admission lane and can be stopped while waiting.

Progress comes from real tool and pipeline events. Public reasoning output from a backend is shown in a collapsible section when supplied. AGY's documented stream exposes ACTIVE response steps as a phase signal, not reasoning text; Koharu does not manufacture a reasoning transcript from that signal. See the [AGY headless stream reference](https://antigravity.google/docs/cli/headless/). Closing a panel disconnects only its view; it does not cancel native work.

## What context is shared

The Agent starts with a compact overview of the open project and its first batch of page IDs. It reads further page batches with `inspect_project`, semantic layers and regions with `inspect_page`, and available font families with `list_fonts`. These reads are paginated and limited to 64 KiB per response, so large projects do not push the user's request behind a full-project dump. The CLI receives the complete user request before the overview.

The Agent renders and attaches a page image only when it invokes visual page inspection; it does not automatically attach every page.

<Note>
  Agent sign-in and translation-provider credentials are separate. ChatGPT sign-in does not
  configure the pipeline's OpenAI provider, and an OpenAI API key does not sign in the Agent.
</Note>

## Sign out

**Sign out** cancels active work, clears the current Agent session, and removes the Codex account authorization used by Koharu. **New conversation** clears an idle session and releases its retained project. Agent configuration is saved separately from translator settings. Conversation snapshots are bounded in memory for the current application lifetime; closing the application stops work rather than resuming it after restart.

## Platforms

These backends are source integrations for Windows and Linux. Build Koharu for the target OS and install/sign in with the CLI and Node on that machine. Paths are detected locally; Windows executable paths and credentials are not copied to Linux. Windows cancellation stops the process tree; Unix cancellation stops the private process group. The current implementation was exercised on Windows; Linux execution has not yet been verified.
